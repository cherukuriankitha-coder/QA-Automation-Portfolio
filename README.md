A hands-on Python testing portfolio focused on **data validation, ETL quality checks, automated testing, SQL, and QA engineering**.

## About

I'm Ankitha Cherukuri, a data and quality-focused professional with experience using Python, SQL, analytics, and testing concepts. This repository demonstrates practical automated checks that can be used to catch data-quality problems before they reach reports or downstream systems.

## Featured Project: Automated Data Quality Validator

`data_quality_validator.py` provides reusable checks for:

- Missing/null values
- Duplicate records
- Primary/unique key validation
- Required-column/schema validation
- Numeric range and business-rule validation
- Dataset-level quality summaries

Automated tests are included with **pytest** in `tests/test_data_quality_validator.py`.

## Tech Stack

- Python
- Pandas
- PyTest
- SQL
- Data Quality & ETL Testing
- Git & GitHub

## Run Locally

```bash
pip install -r requirements.txt
python data_quality_validator.py
pytest -v
```

## What This Demonstrates

This project shows how automated validation can identify duplicate identifiers, missing required data, invalid numeric values, and schema problems. The same patterns can be adapted for ETL pipelines, reporting datasets, reconciliation workflows, and production data-quality monitoring.
